# Pirx MCP — referencja w Pythonie

Ten katalog zawiera pierwotny prototyp pętli Ollama–MCP oraz serwera MCP. Docelowa, rozwijana implementacja znajduje się w sąsiednich katalogach `../agent` i `../mcp-server` i jest napisana w TypeScript.

Pythonowa wersja pozostaje w repozytorium jako czytelny punkt odniesienia podczas migracji. Nie należy dodawać nowych funkcji równolegle w obu implementacjach.
